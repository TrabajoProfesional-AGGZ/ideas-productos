# Ideas de producto

Análisis, evaluación y resumen de las propuestas temáticas candidatas para el Trabajo Profesional.

📖 **[Ver la documentación online aquí](https://trabajoprofesional-aggz.github.io/ideas-productos/)**

## Sobre este repositorio

Este espacio documenta el análisis de las distintas alternativas consideradas para definir el producto final a desarrollar.

Cada propuesta detalla la necesidad u oportunidad identificada, la solución planteada y en algunos casos una pequeña "Prueba de Concepto (PoC)" a modo de maqueta para tener un primer vistazo del producto.

Desarrollado con [Just the Docs](https://just-the-docs.com/).
